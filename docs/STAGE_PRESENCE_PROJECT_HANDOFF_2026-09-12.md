## The actual problem to solve

Stage Presence lacks **Operational Clarity**.

Greg has:
- a warehouse containing undocumented or incompletely documented inventory
- inconsistent pricing
- employees/contractors whose roles, assignments, and pay need organized representation
- contacts that need to be captured and reusable across jobs
- incomplete job documents / Goodshuffle records
- a need for a unified calendar
- a need to know what equipment is available, committed, used, and underutilized
- pricing, job-cost, payment, and profitability reality that currently depends too heavily on memory and reconstruction

The system should organize this reality before attempting more sophisticated owner dashboards or autonomous intelligence.
