# Presentation Architecture References

For frontend growth, use these together:

- `PRESENTATION_ARCHITECTURE.md` — canonical information hierarchy and progressive-disclosure model.
- `PRESENTATION_BOUNDARY_DECISION.md` — accepted architectural decision that backend growth does not imply frontend growth.
- `FRONTEND_PRESENTATION_CHECKLIST.md` — implementation checklist for deciding whether and how new backend information earns screen space.

The governing rule is: **Store richly. Interpret centrally. Present selectively. Reveal progressively.**
