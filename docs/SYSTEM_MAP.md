## Six governing loops
1. Demand Loop — Relationship → Opportunity → Engagement
2. Solution Loop — Need → Requirements → Solution → Feasibility
3. Commercial Loop — Cost → Price → Proposal → Commitment → Cash
4. Capacity Loop — Equipment + People + Time + Logistics → Deliverability
5. Delivery Loop — Plan → Prepare → Execute → Close
6. Learning Loop — Outcome → Economics → Relationship → Knowledge → Reinvestment
